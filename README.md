# Parallax releases

Signed and notarized builds of the Parallax desktop app (macOS, Apple silicon, macOS 26 or later) and its update feeds. This repository holds release files only; it contains no source code.

- Downloads: the [Releases](https://github.com/zemant91/parallax-releases/releases) page (`Parallax-<version>-arm64.dmg`).
- Update feeds read by the app: `feeds/stable.json` and `feeds/beta.json`.

Parallax is free to use under its license agreement, shown when the app first starts.
